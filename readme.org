#+title: nvim-lab 变更记录与项目规则
#+startup: overview

* 项目目标

从零构建一套属于自己的 Neovim 配置。配置源文件使用 Org Mode 管理，通过 Org Babel tangle 生成 Lua 文件。

* 启动方式

过渡阶段使用独立的应用名，避免读取或写入本机默认 Neovim 配置：

#+begin_src sh
  NVIM_APPNAME=nvim-lab nvim
#+end_src

项目配置目录为 =/home/valjean/.config/nvim-lab=。

* 配置检查

执行 tangle 后，可以在 Neovim 中检查 =signcolumn= ：

#+begin_src vim
:set signcolumn?
:lua print(vim.opt.signcolumn:get())
#+end_src

配置生成后进行无界面启动检查：

#+begin_src sh
  NVIM_APPNAME=nvim-lab nvim --headless "+qa"
#+end_src

项目根目录的 =Makefile= 提供对应的快捷命令：

#+begin_src sh
  make treesitter-install  # 安装或更新常用 Treesitter parser
  make nvim-check          # 无界面启动检查
  make check               # nvim-check 的别名
#+end_src

* 项目规则

1. 优先修改 =nvim-init.org=，不要直接修改由 tangle 生成的 Lua 文件。
2. 每次配置变更都在本文件的“变更记录”中追加日期、目的和验证结果。
3. 新增插件必须说明用途、加载时机和可能的外部依赖。
4. 配置应保持模块化；复杂配置拆分为独立 Org source block，并明确 tangle 目标文件。
5. 修改后至少进行一次无界面启动检查：

   #+begin_src sh
     NVIM_APPNAME=nvim-lab nvim --headless "+qa"
   #+end_src

6. 不覆盖默认 =nvim= 配置，不在没有记录的情况下删除已有配置。

** 远程文件

远程文件不一定需要插件：Neovim 的 netrw 支持 =scp://= 路径，但当前体验更适合单文件编辑；远程项目建议使用 =sshfs= 挂载后交给 nvim-tree 或 Telescope 浏览。后续如需要远程开发，再单独评估远程插件。

** 推荐落地顺序

1. 先确定插件管理器： =vim.pack= 或 =lazy.nvim= 。
2. 安装 Telescope、Treesitter、gitsigns、which-key。
3. 配置 LSP、Mason、blink.cmp 和 conform。
4. 加入 nvim-tree、Markdown 和终端工具。
5. 最后评估 DAP、测试、Trouble 和远程开发工具。

** 选择原则

- 一个问题优先选择一个主要插件，避免功能重叠。
- 优先使用 Neovim 原生能力和小型模块，不为每个细节安装插件。
- 每个插件都要有明确的退出方案：停用后核心编辑能力仍应可用。
- 记录插件的加载事件、外部依赖、快捷键和验证方法。

** 代码折叠

当前使用 Neovim 内置折叠机制和 Treesitter，不额外安装折叠插件。

JSON 文件需要安装并启动对应的 Treesitter parser。首次更新配置后执行：

#+begin_src sh
nvim --headless \
  '+lua require("nvim-treesitter").install({"json", "jsonc"}):wait(300000)' \
  '+qa'
#+end_src

如果仍然显示没有折叠，可以检查当前文件是否有 Treesitter parser：

#+begin_src vim
:InspectTree
:echo &filetype
#+end_src

#+begin_src lua
vim.opt.foldmethod = "expr"
vim.opt.foldexpr = "v:lua.vim.treesitter.foldexpr()"
vim.opt.foldlevel = 99
vim.opt.foldlevelstart = 99
vim.opt.foldenable = true
vim.opt.foldcolumn = "1"
#+end_src

常用操作：

- =za= ：切换当前折叠。
- =zo= ：打开当前折叠。
- =zc= ：关闭当前折叠。
- =zR= ：打开全部折叠。
- =zM= ：关闭全部折叠。
